# PrimeReact with TanStack Start and Tailwind CSS

A TanStack Start starter for [PrimeReact](https://primereact.dev) in Tailwind mode, where the primitives are styled with Tailwind CSS and the PrimeUI tokens. The sample page is built from PrimeReact components and uses a `.dark` class for dark mode and the Inter font.

[Open in StackBlitz](https://stackblitz.com/github/primefaces/primereact-examples/tree/main/tanstack-tailwind-quickstart)

## Run it

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Where to look

- `src/routes/index.tsx` is the page to edit. It also sets up `PrimeReactProvider`.
- `src/styles.css` holds the global styles.

Read more in the [PrimeReact Tailwind docs](https://primereact.dev/docs/tailwind).
