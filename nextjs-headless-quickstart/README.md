# PrimeReact headless with Next.js

A Next.js starter for [PrimeReact](https://primereact.dev) in headless mode, where unstyled hooks give the behavior and the app writes its own markup and styles. The sample page is built from PrimeReact components and uses a `.dark` class for dark mode and the Inter font.

[Open in StackBlitz](https://stackblitz.com/github/primefaces/primereact-examples/tree/main/nextjs-headless-quickstart)

## Run it

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Where to look

- `app/page.tsx` is the page to edit.
- `components/prime-provider.tsx` sets up `PrimeReactProvider`.
- `app/globals.css` holds the global styles.

Read more in the [PrimeReact headless docs](https://primereact.dev/docs/headless).
