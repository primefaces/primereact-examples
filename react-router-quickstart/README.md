# PrimeReact with React Router

A React Router starter for [PrimeReact](https://primereact.dev) in styled mode, where the components come pre-themed and are driven by design tokens. The sample page is built from PrimeReact components and uses a `.dark` class for dark mode and the Inter font.

[Open in StackBlitz](https://stackblitz.com/github/primefaces/primereact-examples/tree/main/react-router-quickstart)

## Run it

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Where to look

- `app/routes/home.tsx` is the page to edit.
- `app/root.tsx` sets up `PrimeReactProvider`.
- `app/app.css` holds the global styles.

Read more in the [PrimeReact styled mode docs](https://primereact.dev/docs/styled).
