# PrimeReact with Vite and Tailwind CSS

A Vite starter for [PrimeReact](https://primereact.dev) in Tailwind mode, where the primitives are styled with Tailwind CSS and the PrimeUI tokens. The sample page is built from PrimeReact components and uses a `.dark` class for dark mode and the Inter font.

[Open in StackBlitz](https://stackblitz.com/github/primefaces/primereact-examples/tree/main/vite-tailwind-quickstart)

## Run it

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Where to look

- `src/App.tsx` is the page to edit.
- `src/main.tsx` sets up `PrimeReactProvider`.
- `src/index.css` holds the global styles.

Read more in the [PrimeReact Tailwind docs](https://primereact.dev/docs/tailwind).
