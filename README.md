# PrimeReact examples

Example projects for [PrimeReact](https://primereact.dev) v11. Each folder is a complete app with its own README, and all of them open on StackBlitz.

## Modes

PrimeReact v11 can be used in four ways:

- [Styled](https://primereact.dev/docs/styled) components come pre-themed and are driven by design tokens.
- [Headless](https://primereact.dev/docs/headless) hooks give the behavior, and the app writes its own markup and styles.
- [Primitive](https://primereact.dev/docs/primitive) components are unstyled, and the app styles them itself.
- [Tailwind](https://primereact.dev/docs/tailwind) mode styles the PrimeReact primitives with Tailwind CSS and the PrimeUI tokens.
