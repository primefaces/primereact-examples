# PrimeReact with TanStack Start

A TanStack Start starter for [PrimeReact](https://primereact.dev) in styled mode, where the components come pre-themed and are driven by design tokens. The sample page is built from PrimeReact components and uses a `.dark` class for dark mode and the Inter font.

[Open in StackBlitz](https://stackblitz.com/github/primefaces/primereact-examples/tree/main/tanstack-quickstart)

## Run it

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Where to look

- `src/routes/index.tsx` is the page to edit. It also sets up `PrimeReactProvider`.
- `src/styles.css` holds the global styles.

Read more in the [PrimeReact styled mode docs](https://primereact.dev/docs/styled).
