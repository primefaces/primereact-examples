# PrimeReact Examples

Quickstart starters for [PrimeReact](https://primereact.dev) v11, one for each framework and styling mode. Pick the one that matches your stack.

## Modes

PrimeReact v11 offers four approaches:

- [Styled](https://primereact.dev/docs/styled) components come pre-themed and are driven by design tokens.
- [Headless](https://primereact.dev/docs/headless) mode gives you unstyled hooks, and you bring your own markup and styling.
- [Primitive](https://primereact.dev/docs/primitive) components are unstyled, and you style them yourself.
- [Tailwind](https://primereact.dev/docs/tailwind) mode wraps the PrimeReact primitives with Tailwind and PrimeUI tokens.

```bash
npm install
npm run dev
```
